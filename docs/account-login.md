# 账户登录模块

GreenTwin 现已提供 `/login` 账户入口，并为 `/master`、`/sansheng`、`/twin`、`/governance` 四个业务路由增加访问保护。

## 当前实现

- 用户可以在登录页创建本地演示账户，注册后直接进入平台。
- 密码使用随机盐和 SHA-256 摘要后保存在浏览器 `localStorage`，不会保存明文密码。
- “记住账户名称”只记录账户名，不记录密码。
- 登录状态在刷新页面后恢复；退出后访问受保护路由会返回登录页。
- 登录前直接访问业务路由时，认证成功后会返回原目标地址。

## 安全边界

该模块与参考项目一样，定位为比赛演示环境的纯前端认证原型。浏览器本地会话不能替代服务端身份认证，也不适合正式生产环境。

正式部署时，应将注册、登录、会话校验和退出操作替换为后端用户中心接口，并使用安全 Cookie 或后端认可的短期令牌；密码摘要也必须由服务端使用专用密码哈希算法处理。
