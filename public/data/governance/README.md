# 乡村治理问题要素数据

`governance-issues.geojson` 是 GreenTwin 乡村治理模块的场景模拟点要素数据，采用 `OGC:CRS84`（经度、纬度）坐标顺序，共 116 条记录，覆盖兰考县 16 个乡镇（街道）。

数据并非按行政区平均铺点：城区街道和重点镇分配更多记录，每个乡镇内部采用 2–3 个热点中心生成聚集点，并保留约 16% 的离散点；问题类型还会根据城区、农业、沿河和产业等乡镇画像改变权重。固定随机种子保证结果可复现。

属性字段包含问题编号、问题类型、问题描述、乡镇/村庄及代码、详细位置、上报时间、上报渠道、紧急程度和处置状态。模块直接加载该文件，用于属性查询、空间范围查询、地图与列表/详情/图表联动及查询结果导出。

可运行以下命令重新生成：

```powershell
python scripts/generate_governance_issues.py
```

该数据仅用于界面和查询流程演示，不代表真实事件或法定位置。生产环境可保持相同字段结构，替换为 iServer 数据服务查询结果。
