`公园.glb` 使用 Virginia Vidonis 创作的 **City Park at Sunset**，由 Sketchfab
提供的 GLB 转换格式（1K 纹理）下载并替换原公园模型。

- 模型页面：https://sketchfab.com/3d-models/city-park-at-sunset-ec70492df60b4d42b37b7219b7b2149e
- 许可证：CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）
- 修改说明：文件重命名为 `公园.glb`，并在场景中调整显示比例；模型内容未修改

该资源用于“三生模拟”中的公园选址与 Mapbox 等时圈分析演示。使用或再分发时
须保留上述作者、模型来源与许可证信息。
